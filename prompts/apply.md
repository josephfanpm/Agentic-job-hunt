# Apply to a job

Either agent can submit. Work through the checklist in [AGENTS.md](../AGENTS.md#auto-apply-checklist) first.

1. **Referral check.** Does the user know anyone at the company (the Network tab, or a Name match in their connections)? If so, stop and ask whether to request a referral first. Most referral systems want the referrer to submit before you apply, using the same email. If the user has already applied, the referrer can flag them to the recruiter directly.
2. **Tailor** using [tailor-resume.md](tailor-resume.md).
3. **Fill the form** with facts from `private/profile.md` only.
   - **Sponsorship or work-authorization questions:** ask the user. Answers depend on the visa type and how each company words the question.
   - **Short essays** ("tell us about a project…"): 100–200 words. Use the situation, what you did, and the result with a number. Use the project closest to the job.
   - **Salary:** use the posted range or the user's floor from the profile. Never go below the floor.
   - **Location or relocation:** say yes to relocating without naming a preferred city, unless the user says otherwise.
4. **Submit**, or hand back to the user if a captcha, an account login or an assessment blocks you. Never fight a captcha.
5. **Log it** in the Applied tab the same day, with Channel: Referral, Hiring manager message, Cold application or Auto-apply. Tick Applied on the Daily jobs row.
6. **Draft one message** to someone on the team, using [outreach.md](outreach.md), and put it in the job's Message cell for the user to send.
7. **Set Follow up on** to 7 days out.

## Measure what works

After about 3 weeks, count interviews by Channel in the Applied tab. Put more effort into the channels that produce screens and less into the rest.
